# Skor Tahmin

Telefonda ana ekrana eklenebilen maç tahmin uygulaması: **https://aydinoglucaglar83.github.io/superlig/**

- Veriler football-data.co.uk'tan canlı çekilir (Süper Lig, Avrupa'nın 5 büyük ligi, diğer ana ligler ve 16 ek lig).
- Eski Python algoritması (form, ev/deplasman, rakip ağırlıklı skor, gol, beraberlik) + Poisson + piyasa oranları.
- Model ağırlıkları sezonun oynanmış maçları üzerinde geriye dönük testle her yenilemede otomatik ayarlanır.
- Değerli oran tespiti, tahmin kaydı ve tuttu/tutmadı takibi.
